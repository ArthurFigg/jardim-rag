# Jardim: o RAG vale a pena? / Is RAG worth it?

Jardim digital (notas ligadas entre si) com o que medi sobre usar RAG ou só a busca por palavras (Grep) numa pasta de notas, e um roteiro para você conferir no seu caso.

A digital garden with what I measured about using RAG versus plain keyword search (Grep) over a folder of notes, and a script to check it in your own case.

Os testes foram feitos com o Claude Code, a pedido meu, nas minhas notas de um RPG de mesa. É um caso só; a página diz o que ainda não foi medido. / The tests were run by Claude Code at my request, on my tabletop-RPG notes. One case only; the page says what is still unmeasured.
